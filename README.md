# Luxe Living Studio

Luxe Living Studio is a personal project for creating Pinterest content focused on home decor, minimalist interiors, and cozy living spaces.

## Project Purpose
- Generate Pinterest Pin ideas, titles, and descriptions.
- Organize content drafts and publishing schedules.
- Allow the account owner to review and select each Pin before publishing.
